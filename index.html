Introducing IntForge

Built to simplify OIC activities, from monitoring and diagnosis to bulk downloads, operations, documentation and Fusion checks — in one workspace for OIC, Fusion, IDCS and VBCS teams.

Monitoring

Red alert cards when an agent is down, a certificate expires or emails are suppressed. A health score per integration, run stats visualised across multiple graphs, and monitoring of just the set you care about.

Bulk Downloads & Search

Download all integrations in one go, the metadata of all connections, and search across all lookups — without opening each one.

Diagnose in Bulk

Download logs for many integrations in one ZIP, trace many integrations at once, and spot integrations that have not run in 32 days.

Operate at Scale

Bulk activate and deactivate, reactivate everything on a connection even above 100, and manage integrations around a Fusion outage.

Post-Development, Faster

Design documents, release notes, call graphs, Swagger and Postman collections generated from the live instance, plus side-by-side version comparison.

Fusion & Identity

Compare FBDI files, check Fusion user roles and IDCS status, browse events and BIP report history. FusionConnect adds a SQL editor, schema browser and BI Publisher reports.

AI built into the workflow

  • OIC Agent: ask in plain language about instances, errors, schedules, agents or flow design.
  • Multi-model error analysis: compare several AI models on the same error, side by side.
  • AI log explanation: download the logs, then let AI explain what the flow did and where it failed.
  • AI query assistant (FusionConnect): get help writing Fusion SQL inside the editor.
  • Integration Analyzer & Multi AI Chat: technical analysis of an integration, and chat with several models at once.
  • Your choice of model: pick the model per feature; admins can assign models per user.

Platform Overview
What is IntForge?

Two jobs in one workspace: simplify the monitoring of your OIC activities, and speed up everything that comes after development.

Monitoring, Simplified

Alerts that turn red when an agent is down, a certificate expires or the file server fills; a health score per integration; multi-graph analysis of instances; and a view of what has not run in 32 days.

Diagnose and Resolve Faster

Bulk log download with AI to explain the log, multi-model AI analysis of errors, and email, ticket or Teams straight from the error row — so problems get fixed, not just found.

Post-Development, Faster

After the build comes the paperwork and the rollout. Generate design documents, release notes, call graphs, Swagger and Postman collections from the live instance, and compare versions side by side.

Operate Without the Repetition

Bulk activate, deactivate and trace dozens of integrations, reactivate everything on a connection even above 100, and manage integrations around a Fusion outage.

A Dashboard That Tells You What Needs Attention

Number of emails sent, suppressed emails, agents and more — brought to one place and visualised, so the state of your OIC instance is easy to understand.

Alert Cards

OIC alone: each of these lives on a different page that you have to open and check.

Design & Explore
Build & Design
See How Everything Fits Together

OIC shows you one integration at a time. These tools show the whole picture and what changed.

Call Graph

Which integrations call which — and which call them — with their connections and target systems; export as PNG or draw.io. Plus AI analysis of a parent integration and all its child integrations in one go, downloadable as a Word document. Know the impact of a change before you make it.

Not in the OIC console

Compare Integrations

Compare two versions of an integration, or two projects, from IAR files: flow diagrams side by side (and full screen), including orchestrations with multiple endpoints. See exactly what changed between releases.

Not in the OIC console

Flow Diagram

Load an active integration and see its adapter flow as a diagram, or design a new one from scratch and export it.

OIC Design Time

Integrations, connections, lookups and agents browsable together — plus download every integration (IAR) in one go, the metadata of all connections, and all lookups as ZIP or CSV. Perfect for backups, audits and migrations.

OIC alone: download an archive, a connection or a lookup one at a time.

Document & Generate
Build & Design
Documentation That Writes Itself

OIC holds the design but not the paperwork. Select the integrations, click Generate — it runs in the background and notifies you when ready.

Generate TDD

A technical design document per integration, with its flow diagram and draw.io diagram, and the connections, agents, lookups and libraries it depends on. Select many, get one ZIP. Built from the live instance, so it matches what is deployed.

Not in the OIC console

Release Notes

Pick active integrations and projects and get release notes with the integration table, every connection’s properties and the lookup data, as Word documents.

Not in the OIC console

API Swagger and Postman

Browse an active integration’s Swagger spec and generate a ready-to-import Postman collection, environment and test suite — for one integration or in bulk.

Not in the OIC console

iCal Generator

Just select the combination and the iCal rule is ready to use in OIC — no syntax to learn, no trial and error.

HealthyWarningCritical

Monitor Your Own Set

Diagnose
Monitor & Diagnose
Diagnose in Bulk, Not One by One

The console works on one integration at a time. These tools work on the whole estate.

Download Logs, Then Understand Them

Select many integrations and download all their activity logs in one ZIP, search across them, and let AI explain the log — what the flow did and where it went wrong.

OIC alone: open and download one instance’s log at a time.

Bulk Tracing

Switch Debug tracing on or off for many integrations at once — and back off again, so tracing is never left running.

OIC alone: tracing is switched per integration.

Last Run

The last run time and instance id of every active integration over 32 days, so integrations that are active but not in use stand out.

Not in the OIC console

Integration Mapper

Map integrations to business functionalities (upload and download as Excel) so monitoring, outages and reports can work by function, not by name.

Not in the OIC console

Integration Purpose

OIC’s own AI summary of every active integration, collected for all of them in the background — an instant catalogue of what each one does.

OIC File Server

Save directories as favourites and see the files in them (names, not content) from IntForge, plus file server configuration, rights and quota with a warning as it fills.

Bulk Operations

Fusion Outage Control

Record the integrations to act on during a planned or unplanned Fusion outage, with their functionality and state, and manage them as one list.

Not in the OIC console

Fusion & IDCS
Fusion & IDCS
Fusion and Identity, Next to OIC

Fusion user roles, IDCS user status and the OIC file server — one platform for ease of monitoring, instead of a login to each.

Compare FBDI

Upload two FBDI template ZIP files and see file, column and row differences with a quick status — no more eyeballing spreadsheets.

Reports History

BIP report run history with daily trends, execution-time analysis, reports slower than a threshold you set highlighted, and upcoming scheduled runs.

Fusion Users

Look up a user’s roles, compare two users, or compare the same user across two environments to find role gaps.

Fusion Events

Business events catalog, subscriptions and event queue status in one browsable place.

ESS Monitoring (preview)

Health of Fusion ESS jobs: failures, runtime regressions, SLA and stuck-job risk.

IDCS Users

See each user’s roles and status — active, deactivated or locked — with filters and counts, straight from IntForge. No need to log in to IDCS.
